## Agents and packaging

All six agent definitions were reviewed. Akka and DocFX personas retain their publisher/institutional practices ([Akka](https://getakka.net/), [DocFX](https://dotnet.github.io/docfx/)). Concurrency, performance and benchmark personas now respect the Revit domain boundary. BenchmarkDotNet multiple baselines are valid in separately grouped categories; no erroneous correction to that advice was retained ([categories](https://benchmarkdotnet.org/articles/features/categories.html)).

The Roslyn agent's cache test now claims only output stability: equal generated text does not prove cache reuse. Verify actual incremental-step reasons when testing caches ([Roslyn generator cookbook](https://github.com/dotnet/roslyn/blob/main/docs/features/incremental-generators.cookbook.md)). Hard-coded benchmark ratios remain historical observations requiring measurement on the selected runtime.

Plugin manifests, version lockstep, registration/index, complete-reference copying and release metadata were checked. Repository CI actions are SHA-pinned and checkout credentials are not persisted. Structural checks are not schema certification by every assistant runtime; no claim is made that all four clients were installed and exercised.

## Evidence still requiring a target environment

Every inherited skill was covered by source review; **not every assertion is independently proven**. Unresolved portions include empirical throughput ratios, every distro/browser certificate-store combination, evolving third-party API examples, generated source output and full infrastructure workflows. They are not overwritten merely because Microsoft recommends something different. Verify the particular version and workload when adopting them. Actual Revit load/transaction/API-drift tests require the supported licensed Windows hosts; they were not run here.
